## Laboratorio 8 Parte 2

Se implementó una galería de imágenes para cada propiedad, permitiendo visualizar múltiples fotos en una vista de miniaturas y abrirlas en un modal a pantalla completa con soporte de navegación por teclado.

**Video de explicación:** https://youtu.be/l8w9pHvkt9k

### Definition of Done

| Criterio | Descripción | Estado |
|----------|-------------|--------|
| Thumbnails grid | Imágenes de la propiedad mostradas como miniaturas clickeables | ✅ |
| Modal opens | Click en miniatura abre vista a pantalla completa | ✅ |
| Navigation arrows | Botones izquierda/derecha para navegar entre imágenes | ✅ |
| Keyboard support | Teclas de flecha y Escape funcionan correctamente | ✅ |
| Image counter | Muestra posición actual (ej. "3 de 10") | ✅ |
| Close button | Botón X para cerrar el modal | ✅ |
| Backdrop click | Click fuera de la imagen cierra el modal | ✅ |
